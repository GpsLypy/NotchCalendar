# Changelog v0.3.0 → v0.3.1

Comparison scope: `v0.3.0` to the v0.3.1 release working tree. Test and documentation changes are excluded from the change analysis.

## Features

- None. This is a focused visual maintenance release.

## Bug Fixes

- Shorten the compact notch surface from 34 to 30 points so it no longer extends too far below the menu bar.
- Tighten the lower corner radius from 11 to 9 points while preserving the existing notch width, 12-point typography, top-edge anchoring, and 10-point hover buffer.

## Chore

- Bump the app version from 0.3.0 (build 13) to 0.3.1 (build 14).
