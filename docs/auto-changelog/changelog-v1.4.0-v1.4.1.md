# v1.4.0 → v1.4.1

## Features

- 文件浮窗新增选中项操作：
  - 工具栏常驻打开、复制、刷新和访达定位按钮。
  - 支持 Return 打开与 `⌘C` 复制。
  - 复制写入标准 macOS file URL，可粘贴到访达或其他应用。
- 刘海悬停新增快速、平衡和防误触三档响应速度。

## Bug Fixes

- SwiftUI 刘海宿主接收 AppKit first-mouse，修复第一次点击仅激活面板、需要再次点击的问题。
- 文件行单击选择与双击打开独立识别，减少单击等待。
- 默认悬停确认与展开动画总时长由约 670ms 降至约 340ms。

## Chore

- 新增文件剪贴板、首击、悬停档位、偏好持久化及备份校验测试。
- 保存两轮有效优化性能样本和 1,000 项目录扫描预算结果。
