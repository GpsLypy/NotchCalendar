# v1.3.0 → v1.4.0

## Features

- 文件浮窗由单目录升级为最多 12 个收藏目录：
  - 左侧 Finder 式“个人收藏”侧栏用于切换目录。
  - 设置页支持添加、排序、访达定位和移除收藏。
  - 收藏顺序和当前选中目录跨启动保留。
- 文件区域改为 Finder 式列表：
  - 展示名称、修改日期、大小和种类列。
  - 文件夹支持披露箭头行内展开。
  - 支持双击进入目录以及前进、后退导航。
  - 使用系统文件图标、类型说明、选中状态和交替行底色。

## Bug Fixes

- 自动迁移 1.3.0 的单目录 bookmark，升级后无需重新选择原文件夹。
- 应用包与符号链接不进行递归树展开，避免目录循环；导航仍执行根目录边界检查。
- 新版多目录 bookmark 继续排除在本地备份之外。

## Chore

- 更新中英文文件浮窗文案、README 与原生布局捕获。
