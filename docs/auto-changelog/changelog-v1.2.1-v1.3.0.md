# v1.2.1 → v1.3.0

## Features

- 新增刘海文件浮窗：
  - 用户可选择并持久化一个本地根目录。
  - 支持根目录内的文件夹导航、文件打开、访达定位和路径复制。
  - 支持把文件从浮窗拖到其他应用。
  - 支持按名称或修改时间排序，并可选择是否显示隐藏文件。
  - 目录内容变化后自动刷新，关闭功能后停止监听。
- 新增紧凑刘海文件拖拽触发：
  - 访达文件进入刘海接收区时自动展开文件页。
  - 拖拽仅用于打开浮窗，不复制、移动或删除原文件。
- 新增目录访问边界保护：
  - 使用 bookmark 恢复用户选择的目录。
  - 解析符号链接后校验路径，禁止导航到所选根目录之外。
  - 目录 bookmark 不进入本地备份。

## Bug Fixes

- 使用独立窄幅非激活面板接收 Finder 拖拽，避免文件浮窗启用后主刘海面板遮挡两侧菜单栏控件。
- 区分点击展开与拖拽展开，避免拖拽文件时刘海面板取得键盘焦点而中断 Finder 操作。
- 为文件页分配独立 `⌘3` 快捷键，避免与专注页 `⌘2` 冲突。

## Chore

- 新增文件浮窗中英文界面文案和设置项。
