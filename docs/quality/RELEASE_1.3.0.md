# Notch Calendar 1.3.0

版本 1.3.0（build 28），支持 macOS 15+、Apple 芯片和 Intel。沿用仅 ad-hoc 签名、无 Developer ID 或 Apple 公证的 DMG 手动安装流程。

- 展开刘海新增文件浮窗，可选择一个本地文件夹并在限定范围内导航。
- 支持打开文件和文件夹、在访达中定位、复制路径，以及把文件拖到其他应用。
- 支持名称或修改时间排序、隐藏文件开关、目录变化自动刷新和 bookmark 恢复。
- 访达文件拖到紧凑刘海时自动打开文件页，不复制、移动或删除原文件。
- 独立窄幅非激活拖放面板避免遮挡两侧菜单栏，拖拽展开不会从访达抢走键盘焦点。
- 符号链接不能导航到根目录之外，机器相关的目录 bookmark 不进入本地备份。

## 验证

- 完整 Xcode 工具链下，Swift 编译与 251 项测试完成：240 项通过、11 项可选测试跳过、零失败。
- 文件浮窗 5 项专项测试覆盖隐藏文件、排序、bookmark 恢复、符号链接边界以及拖放面板展开生命周期。
- 600 × 460 原生 SwiftUI 文件页离屏渲染通过，中文文件名、系统图标、元数据和工具栏无重叠。
- Release 配置编译和 20 项发布工具测试通过。
- Universal 2 打包、ad-hoc 签名、DMG 挂载核验和上传由 [Release 工作流](https://github.com/GpsLypy/NotchCalendar/actions/workflows/release.yml)执行，最终结果以该版本运行记录为准。
