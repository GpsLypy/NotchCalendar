# Notch Calendar 1.2.1

版本 1.2.1（build 27），支持 macOS 15+、Apple 芯片和 Intel。沿用仅 ad-hoc 签名、无 Developer ID 或 Apple 公证的 DMG 手动安装流程。

- 刘海面板启动时优先使用可用内置屏幕，修复外接显示器为主屏或拥有键盘焦点时面板出现在外接屏的问题。
- 显示器变更和唤醒时使用同一选择规则；合盖时回退到可用外接屏，内置屏恢复后自动返回。
- 仅外接屏可用时，保留当前仍连接的屏幕，避免随键盘焦点在外接屏之间移动。
- `.gitignore` 忽略本地宣传素材和导出物，已有跟踪的脚本、文档继续保留；这些本地素材不参与发布构建。

## 验证

- 本地完整 Xcode 工具链下，Swift 编译与 246 项测试完成：236 项通过、10 项可选测试跳过、零失败。
- 新增 8 项屏幕选择测试，覆盖外接屏为主屏、合盖回退与开盖恢复的模拟屏幕列表、断连、焦点变化及空屏幕列表。
- 当前内置屏和 24V5 外接屏连接时，原生 `NSScreen` 选择测试实际通过：传入外接屏为当前屏幕后仍选中内置屏，展开面板矩形处于内置屏范围内。
- 发布工具 20 项测试通过。云端测试、Universal 2 打包、签名与 DMG 挂载核验和上传由 [Release 工作流](https://github.com/GpsLypy/NotchCalendar/actions/workflows/release.yml)执行，最终结果以该版本运行记录为准。
