# Notch Calendar 1.4.0

版本 1.4.0（build 29），支持 macOS 15+、Apple 芯片和 Intel。沿用仅 ad-hoc 签名、无 Developer ID 或 Apple 公证的 DMG 手动安装流程。

- 文件浮窗从单目录升级为最多 12 个收藏目录，使用 Finder 式“个人收藏”侧栏切换。
- 设置页支持批量添加、上移、下移、访达定位和移除收藏目录。
- 文件区域展示名称、修改日期、大小和种类列，文件夹可通过披露箭头行内展开。
- 支持双击进入文件夹以及前进、后退导航；文件操作和拖出能力保持不变。
- 自动迁移 1.3.0 保存的单目录 bookmark，保留原目录，无需重新选择。
- 应用包和符号链接不递归展开，所有目录导航继续受当前收藏根目录边界约束。

## 验证

- 完整 Xcode 工具链下，Swift 编译与 254 项测试完成：244 项通过、10 项可选测试跳过、零失败。
- 文件浮窗 8 项专项测试覆盖多收藏、顺序与选中持久化、1.3.0 迁移、历史导航、行内目录展开、隐藏文件、排序及符号链接边界。
- 600 × 460 原生 SwiftUI 渲染验证 Finder 式侧栏、四列表头、展开层级和长文本边界；540 × 560 设置页渲染验证多目录管理控件。
- Release 配置编译和 20 项发布工具测试通过。
- Universal 2 打包、ad-hoc 签名、DMG 挂载核验和上传由 [Release 工作流](https://github.com/GpsLypy/NotchCalendar/actions/workflows/release.yml)执行，最终结果以该版本运行记录为准。
