本次关键回归覆盖：

- 提醒身份与改期、隐藏/拒绝/取消、过期跳过、延后上限、跨来源别名、睡眠/唤醒重排、通知拒绝、热键冲突、入会失败。

- 专注标签持久化、暂停/重启/完成、旧记录兼容、损坏快照不覆盖、周统计夏令时和边界、CSV 转义及公式保护、快捷指令不覆盖运行或暂停计时。
