# NotchCalendar 4.3.16

## 本次更新

- 在刘海查看 Claude Code 和 Codex 的本机 Shell 命令及其工作目录，一次性允许或拒绝。功能默认关闭，可在「设置 → AI 用量 → 刘海命令审批」开启并配置钩子。
- 新增截图和剪贴板历史的可配置全局快捷键，默认关闭。
- 应用显示名称统一为 NotchCalendar（曾用名 superNotch）。升级沿用现有数据和授权。

macOS 15+，Apple 芯片与 Intel 通用包，build 209。采用 ad-hoc 签名，需手动安装。

## What's new

- Review local Claude Code and Codex shell requests from the notch. See the command and working directory, then allow it once or deny it. Enable the feature and configure the hooks in Settings → AI usage → Notch command approvals.
- Configure global shortcuts for Smart Screenshot and Clipboard History. Both are off by default.
- The app is now named NotchCalendar. Existing data and licenses carry over.

macOS 15 or later. Universal for Apple silicon and Intel, build 209. Ad-hoc signed. Install manually.
