# superNotch 4.3.15

## 4.3.15 的更新

- 翻译网页的服务切换、缩放、刷新、独立窗口和更多菜单使用独立的点击区域，默认缩放保留 50%。
- 智能助理的任务与续聊输入框聚焦时高亮边缘，回车发送，Shift + 回车换行。中文输入法组字期间回车仍用于确认候选词。执行详情与正文左对齐。
- 调整截图和录制控制面板。截图完成后可在刘海下方查看结果提示。
- 图片压缩完成后可直接查看输出文件。
- 调整音乐跨刘海状态的显示，以及专注、编程活动和桌面小伴侣的呈现。

macOS 15 及以上，Apple 芯片与 Intel 通用包，build 208。采用 ad-hoc 签名，尚未公证，请手动安装。

## What’s new in 4.3.15

- Give translation controls their own click targets for switching services, zooming, reloading, opening a separate window, and showing more actions. The default zoom remains 50%.
- Highlight focused assistant inputs. Press Return to send or Shift + Return for a new line. Return confirms an active Chinese IME candidate first. Execution details align with the result text.
- Refine the capture and recording controls, and show a receipt below the notch after saving a screenshot.
- Open the output file directly after compressing an image.
- Refine music across notch states and adjust the presentation of focus, coding activity, and desktop companions.

macOS 15 or later. Universal for Apple silicon and Intel, build 208. Ad-hoc signed. Install manually.
