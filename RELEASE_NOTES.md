# NotchCalendar 4.4.0

## 本次更新

- 工作台侧栏默认显示今天、日历、待办、AI 工作台、全部工具和设置。常用工具可固定，也可用快捷键或快速入口打开。日历集中搜索、显示和新建操作，设置按外观与刘海、快捷键与自动化、AI 与服务等重新分组。
- 截屏快捷键打开统一的采集面板，提供区域和全屏截图、区域录屏、滚动截图与文字识别。选定区域后向下滚动即可连续拼接长图。剪贴板历史可从刘海打开，工具快捷键可自定义。
- 蓝牙和 USB 配件连接、外置磁盘挂载时，刘海会显示相应提示。新增屏幕护眼，可独立调整色温与调暗程度，也可设置生效时段。
- 修复刘海收起时专注倒计时未及时刷新的问题。编程审批支持在当前会话内记住已审阅的相同命令。
- 软件更新支持后台下载和安装前确认。此临时签名发行包采用手动覆盖安装，更新页提供相应指引。

构建号 218。支持 macOS 15 及以上、Apple 芯片和 Intel。

## What’s new

- The workspace sidebar now starts with Today, Calendar, To-do, AI Workbench, All Tools and Settings. Pin favorite tools or open them with existing shortcuts and Quick Access. Calendar groups search, display and creation actions, and Settings groups related controls.
- The screenshot shortcut opens a capture chooser for area and full-screen screenshots, area recording, scrolling screenshots and text recognition. Scroll down after selecting a region to stitch a long screenshot continuously. Open clipboard history at the notch and customize global tool shortcuts.
- The notch shows a notice when macOS connects Bluetooth or USB accessories or mounts an external drive. Screen Comfort adds separate warmth and dimming controls with an optional schedule.
- Fixed Focus countdown refresh while the notch is collapsed. Coding approvals can remember a reviewed command for repeats in the same session.
- Software Update can download in the background and asks before installation. This ad-hoc signed build uses manual replacement, with instructions in Software Update.

Build 218 requires macOS 15 or later on Apple silicon or Intel.
