# NotchCalendar 4.3.20

## 本次更新

- 统一官网、GitHub 与应用内检查更新的安装包，DMG 和 ZIP 内均为 NotchCalendar.app，修复重新安装后变成 superNotch 的问题。
- 官网与应用内更新共用同一份 DMG 和校验值。
- 升级前退出旧版；若「应用程序」中有 superNotch.app 或 Notch Calendar.app，将旧副本移到废纸篓但暂不清空，再安装 NotchCalendar.app。确认数据和授权正常后再清理旧副本。
- 包含 4.3.19 的待办悬停修复、刘海命令「允许并记住」与滚动截图。

macOS 15+，Apple 芯片与 Intel 通用包，build 213。临时签名，需手动覆盖安装。

## What's new

- The website, GitHub release and in-app update checker now provide the same DMG containing NotchCalendar.app. Reinstalling an update no longer changes the app filename to superNotch.
- The website and update checker share the same installer and checksum.
- Quit the old app. Move any superNotch.app or Notch Calendar.app copy from Applications to Trash without emptying it, then install NotchCalendar.app. Verify existing data and activation before removing the old copy permanently.
- Includes the Todo hover fix, remembered command approvals and scrolling screenshots from 4.3.19.

macOS 15 or later. Universal for Apple silicon and Intel, build 213. Ad-hoc signed; manual installation required.
