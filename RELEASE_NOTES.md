# NotchCalendar 4.4.1

## 简体中文

- 刘海顶部新增分享按钮，可分享小红书主页、官网和公开 GitHub 仓库，也可复制链接并打开微信。
- 重新调整刘海工具栏和工具切换，并优化日历工作台及截图操作。
- 新增邮件验证码工具，支持配置邮件账户后读取验证码。
- 调整软件更新流程。下载完成后可确认安装，或稍后处理。

支持 macOS 15 及以上、Apple 芯片与 Intel Mac。本版使用临时签名，请手动覆盖安装。

## English

- Share the RedNote profile, official website, or public GitHub repository from the notch toolbar. The menu can also copy the link and open WeChat.
- Updated the notch toolbar and tool switching, with refinements to the calendar workspace and screenshot controls.
- Added a mail verification code tool for configured mail accounts.
- After a software update downloads, choose when to install it.

Supports macOS 15 or later on Apple silicon and Intel Macs. This ad-hoc signed build requires manual installation.
