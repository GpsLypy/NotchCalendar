# Notch Calendar 2.0.16

- 无刘海屏幕的中间日期时间条及左右提醒气泡改为完整圆角胶囊形，收紧提醒气泡的黑色背景。

本次按所有者要求跳过新增发行回归，未宣称本版本完成回归。通用编译、安装包完整性及上传资产元数据核验通过。人工鼠标手感、VoiceOver、实体屏幕拔插／合盖、睡眠唤醒、真实服务和持续 CPU／能耗仍待验收。
